## 📖 نظرة عامة

**منصة رصد التعليمية (Rasd Educational Platform)** هي موقع تعريفي رسمي وتفاعلي لتطبيق رصد المخصص لإدارة المنشآت التعليمية والسناتر والدروس الخصوصية.

تتيح المنصة للمعلمين، مدراء المراكز، والمشرفين الإداريين استعراض إمكانيات التطبيق وتنزيل ملف التثبيت المباشر (**APK**) لأجهزة أندرويد.

---

## 🚀 المميزات الرئيسية

- **👥 إدارة الطلاب:** متابعة بيانات الطلاب الأكاديمية والمالية بدقة وسهولة.
- **📋 إدارة المجموعات:** جدولة مواعيد الحصص وتنظيم الفرق الدراسية.
- **☑️ الحضور والغياب:** تسجيل حضور وغياب الطلاب بتقنية كود الـ QR والتقارير الفورية.
- **👨‍🏫 إدارة المعلمين والصلاحيات:** أدوار مخصصة لكل من (المدير، المعلم، السكرتير الإداري).
- **📝 الاختبارات والنتائج:** بنك أسئلة متكامل وإدارة امتحانات دورية وتقييم للطلاب.
- **💳 المدفوعات والمصروفات:** رصد الرسوم الدراسية والمتأخرات وسندات الصرف.
- **📊 لوحة تحكم وتقارير:** إحصائيات بيانية دقيقة لدعم اتخاذ القرارات الإدارية.
- **🌙 دعم الوضع الليلي والنهاري (Dark / Light Mode):** تجربة استخدام مريحة مع تناسق ألوان راقي.
- **📱 تصميم متجاوب 100%:** يعمل بسلاسة على شاشات الهواتف، الأجهزة اللوحية، والشاشات الكبيرة.

## 📸 صور من داخل التطبيق

يحتوي الموقع على معرض لقطات شاشات حقيقية عالية الدقة من داخل تطبيق رصد:
1. **لوحة التحكم الرئيسية (Dashboard)**
2. **تفاصيل الطالب وسجل الحضور (Student Profile)**
3. **تفاصيل المجموعة والمواعيد (Group Details)**
4. **شاشة بنك الأسئلة والامتحانات (Exams & Quiz)**
5. **سجل المدفوعات والمصروفات (Expenses & Finance)**
6. **تسجيل الحضور عبر QR Code**
7. **سجل النشاطات والعمليات (Activity Log)**
8. **ملف المعلم وصلاحياته (Teacher Profile)**
9. **إضافة معلم جديد (Add Teacher)**
10. **واجهة الطالب لتسليم الاختبارات (Exam Submission)**

## 📥 تحميل تطبيق رصد (APK)

تطبيق رصد متاح للتحميل المباشر لأجهزة الأندرويد:
- حجم الملف: **~42 ميجابايت**
- صيغة الملف: **Android APK (`Rasd-app.apk`)**
- يدعم جميع إصدارات أندرويد الحديثة.

يمكن التنزيل بنقرة واحدة من أي زر "تحميل التطبيق" في الموقع أو مباشرة من مسار المشروع:
```bash
src/app-release.apk
```

## 💻 التشغيل والتطوير المحلي

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث)
- مدير الحزم `npm` أو `pnpm`

### خطوات التثبيت والتشغيل

1. **استنساخ المستودع (Clone):**
```bash
git clone https://github.com/username/rasd-educational-platform.git
cd rasd-educational-platform
```

2. **تثبيت الحزم (Install):**
```bash
npm install
```

3. **تشغيل خادم التطوير (Development):**
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:8443` أو `http://localhost:5173`

4. **فحص الأنواع (Typecheck):**
```bash
npm run typecheck
```

5. **بناء النسخة الإنتاجية (Production Build):**
```bash
npm run build
```
سيتم إنشاء المخرجات المحسنة داخل مجلد `dist/`.

## 🌐 النشر على GitHub Pages

المشروع مُجهز بالكامل للرفع على GitHub والنشر التلقائي عبر **GitHub Actions**:

1. أنشئ مستودع جديد على GitHub (مثلاً: `rasd-educational-platform`).
2. قم برفع المشروع:
```bash
git init
git add .
git commit -m "feat: initial commit for Rasd Educational Platform"
git branch -M main
git remote add origin https://github.com/username/rasd-educational-platform.git
git push -u origin main
```
3. اذهب إلى إعدادات المستودع على GitHub:
   - **Settings** > **Pages** > **Build and deployment**.
   - اختر **Source**: `GitHub Actions`.
4. سيتم نشر الموقع تلقائياً على الرابط:
   `https://<username>.github.io/rasd-educational-platform/`
